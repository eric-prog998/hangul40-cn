# 韩语 40 音｜中文闯关版 v46

面向中文母语者的韩语入门练习网站：从 19 个辅音、21 个元音开始，通过听辨、拼读、词句回忆和键盘小游戏逐步熟悉韩文。

本次从 GitHub v42 累计同步到已上线的 v46，包含 v43～v46 的功能、修复、测试与文档。保留原仓库历史和许可证；网站网址不变，更新仓库不会自动部署网站。

## v46 有什么新变化？

- 新增“连续键盘输入”：本页启用后，自评下一张直接开始输入，不必每张再按 T。只有主动自评才自动聚焦，长按的评分数字不会串进下一题。
- 显示答案后按 R 可“遮住答案，再写一次”，先清空旧输入并停止示范，不增加复习次数；明确提示这只是看过答案后的巩固。
- 修复日期切换后旧输入／答案可能重新出现并抢焦点的问题，加固输入法失焦后的快捷键恢复。详见 [v46 版本说明](V46-RELEASE-NOTES.md)。

### 延续 v45 的中文回忆输入

- 今日复习新增“看中文，输入韩文”：聚焦本区按 T，使用系统韩文输入法；Enter 对照参考答案，再用 1／2 自评。
- 区分写法一致、空格／句末标点差异、参考写法不同；不是翻译判题或发音评分，不会自动增加完成量。
- 保护输入法确认与长按；输入框内数字和空格只用于打字。输入不保存、不上传，复习排期和音频保持原样。详见 [v45 版本说明](V45-RELEASE-NOTES.md)。

### 延续 v44 的今日路线

- 新增“今日 10 分钟”：5 项中文回忆、8 次元音听辨和按已有进度推荐的下一小课。
- 短练只做今天剩下的目标项，与原来的 10 项复习共用记录；没有到期或新词时不强凑数量。
- 聚焦路线后用 1／2／3 直接进入，Enter 进入推荐下一步；练习后可返回路线，取消旧音频与自动切题。
- 完成量来自真实自评／作答，打开课程不算完成。刷新、跨日、标签页同步与备份使用原有记录，没有新增打卡存储。详见 [v44 版本说明](V44-RELEASE-NOTES.md)。

### 延续 v43 的音源透明与播放修复

- 新增“音源与发音反馈”：查找全部 492 条现有音频，区分名称／裁切起音／重复起音／元音／完整音节／词句，标出来源与待人工听审状态。
- 可下载待听审清单，或复制、下载某条音频的问题反馈。只生成本地文件／文字，不自动发送，不读取学习记录或申请麦克风。
- 播放控制独立为模块；修复加载中停止却一直等待的情况，保留音频互斥、超时与重试。
- 新增 WebKit 音频专项测试，移除测试中的自动播放限制绕过，并补查网络传输失败。详见 [v43 版本说明](V43-RELEASE-NOTES.md)。

### 延续 v41 的学习功能

- **长期盲听错题**：最近 200 次作答保存在当前浏览器，展示最近 20 次表现；错过的音例连续两次答对后移出待巩固，可单独重练。
- **进度备份与恢复**：在“设置·备份”下载 JSON，另一台设备选择文件、核对摘要后确认合并。已学内容取并集，经验和累计次数取较高值，重复导入不重复加分，每日复习保留较新的记录。
- **按自己的节奏切题**：手动，或 2／3／5 秒自动下一题，默认 3 秒。适用于听音、拼读、词句闯关、元音盲听与收音练习。

## 已有功能

- 40 音表、辅音名称／真人起音、字块拆解与五步入门。
- 六种训练：听音辨字、影子跟读、配对消除、拼读工坊、极速认读、地铁打字。
- 32 个生活词与 20 个句子，支持背诵标记和词句闯关。
- ㅓ／ㅗ、ㅡ／ㅜ 口型对比与 8 题盲听，覆盖元音本音与固定 ㄱ 的完整音节。
- 最长 15 秒的本地录音回听；只有点击开始录音后才申请麦克风权限。
- 今日复习：每天最多 10 项，先回忆再翻面自评，采用透明的 1／3／7 天递进排期。
- 收音第一课：词尾 ㄹ、ㅁ、ㅇ，使用 물、지하철、사람、지금、영수증 五个完整词例。

## 键盘怎么用？

快捷键按当前区域生效，以页面提示为准。输入框内保留正常输入法组合，按钮聚焦时保留原生 Enter／空格行为。

| 区域 | 常用操作 |
| --- | --- |
| 导航 | 顶部 Enter 进入训练场；F2 返回；Shift+1／2／3／4 到训练场／40 音／词句／收音；`[`、`]` 切换游戏 |
| 今日路线 | 聚焦本区：1 进入回忆短练、2 进入盲听、3 接着学；Enter 进入推荐下一步；按钮保留原生键盘操作 |
| 听音与拼读 | 韩国双拼物理键位：R→ㄱ、K→ㅏ、Shift+R→ㄲ、H 后 K→ㅘ；可用数字选项或切换 ASDF 模式 |
| 40 音点读 | 韩文键位直接点读；1 辅音名称、2 真人起音；Enter／空格重播，Backspace 清除组合，Esc 停止 |
| 元音盲听 | 1／2，或 J／H／M／N 对应 ㅓ／ㅗ／ㅡ／ㅜ；空格／F8 重听，Enter 继续，Esc 暂停 |
| 收音练习 | 1／2／3，或 F／A／D 对应 ㄹ／ㅁ／ㅇ；空格／F8 听整词，Enter 继续 |
| 今日复习 | T 输入韩文、Enter 对照／翻面，1 忘了、2 想起来了；揭晓后空格／F8 听示范，R 遮住重写；可勾选连续键盘输入，自评后直接写下一张 |
| 地铁打字 | 系统韩语输入法输入完整词，Enter 提交；IME 确认不同时交卷；F8 或完成组合后 Shift+Enter 重播，Esc 暂停 |

韩文键位模式下 **R 是 ㄱ，不是重播键**。需要选择较短元音而页面仍在等待复合元音的第二键时，可按 Enter 确认。Mac 的 F 键可能需要同时按 Fn。

## 保存、备份与隐私

学习记录保存在当前浏览器，不需要学习账号，也没有账号云同步。换浏览器、换设备或清除网站数据前，请先导出备份。

1. 在“设置·备份”点击“下载进度备份”，保管 JSON 文件。
2. 在另一台设备打开网站，选择备份文件，核对预览内容。
3. 暂停其他标签页的学习，再点击“确认合并恢复”。恢复需要支持 Web Locks 的浏览器，可使用 Chrome。

备份包含已学字母、背熟词句、经验／累计错题、打字最佳、每日复习、近 200 次盲听记录和练习偏好；不包含录音、音频资源或正在进行的题目。导入在浏览器内读取文件，不上传，最大 2 MB。偏好采用备份值，已有学习内容不清空。若提示保存不完整，请保留备份再重试。

录音仅保存在当前页面内存，不上传、不持久保存。分享网站或 GitHub 源码不会同时分享个人学习进度。不要把自己的备份 JSON 上传到公开仓库。

## 本地运行

需要 Node.js `>=22.13.0` 与 npm。当前脚本使用 POSIX 环境变量语法，适用于 macOS、Linux；Windows 可使用 WSL。

```bash
git clone https://github.com/eric-prog998/hangul40-cn.git
cd hangul40-cn
npm ci
npm run dev
```

打开终端输出的本地地址。这是 React 19 + TypeScript + Vinext／Vite 应用，**不能直接双击源码 HTML 运行**。现有学习功能使用随仓库附带的音频，不需要另填 TTS API 密钥。

### 构建与检查

```bash
npx tsc --noEmit
npm test
npm run test:e2e
```

`npm test` 先生产构建再运行测试。v46 有 134 项逻辑／页面测试；其中部分历史交互守卫是源码断言，不等同于完整浏览器端测试。新增路线与输入回忆测试检验实际逻辑与浏览器行为。测试不启用真实麦克风，实体 Mac 韩语输入法仍需要人工验收。

`npm run test:e2e` 是真浏览器测试（Playwright），v46 配置 140 项：113 项 Chromium 全站场景，以及 27 项 WebKit 音频／今日路线／输入复习专项。实际每轮执行范围见对应版本说明。自动构建网站，在本机实际操作全部玩法、新手路线、纯键盘操作、录音、进度保存和备份，并检查控制台错误、未捕获异常、HTTP 错误响应和网络请求失败，排除预期的导航或媒体取消。首次运行前执行 `npx playwright install chromium webkit`；测试只访问本机 `127.0.0.1:4173`。它使用桌面浏览器内核、模拟麦克风和模拟的输入法组合事件，不能替代 Safari／手机真机、实体 Mac 韩语输入法和音质的人工验收。GitHub Actions（`.github/workflows/ci.yml`）会在每次推送和 Pull Request 时自动运行类型检查、lint 和这两套测试。

单独构建／运行生产预览：`npm run build`、`npm run start`。另有 `npm run lint` 可按需执行。测试学习记录请使用独立本地端口，避免修改正式网站的个人进度。

## 网站部署与 GitHub 的区别

这里保存可编辑、可测试的源代码；更新 GitHub **不会自动更新**现有在线网站。当前项目不是直接上传静态文件的 GitHub Pages 项目，也未配置自动发布工作流。

维护现有网站时沿用 `.openai/hosting.json` 的项目配置，由有权限的维护者执行 Sites 构建和部署。项目 ID 是标识，不是访问密钥。Fork 后如需独立部署，请配置自己的项目／托管环境，不要尝试覆盖原站点。不要提交 `.env*`、令牌、个人备份、`node_modules`、构建缓存或本机日志。

## 发音与课程边界

18 个辅音起音来自韩国母语者录音的裁剪。`ㅇ` 作初声静音，作收音读 [ŋ]；起音片段不是可以独立持续发出的完整音，跟读应使用完整音节。ㄹ、ㄲ、ㄸ、ㅃ 的清晰版会重复同一短片段，不是两个不同读法。

完整音节和词句包含固定 AI 示范音频，尚未全部经母语教师逐条听审。听辨得分、跟读完成和复习自评不代表发音准确度；本站没有自动发音评分。收音课只覆盖三类词尾，不是完整七类收音、连读或复杂变音课程。

音频来源与许可见 [HUMAN_CONSONANT_AUDIO.md](HUMAN_CONSONANT_AUDIO.md) 和 `data/consonant-human-clips.json`。后续规划见 [学习路线](LEARNING_ROADMAP_ZH.md)，规划不代表已经实现。
